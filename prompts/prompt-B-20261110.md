### B2 自愈冷跑（不加常驻，dry-run）
```

```
贴完整 JSON 的 `checked / loadable / repaired / refused / held / fresh / healthy / exit` 与三个健康端点的状态码。**这一步不许加 `--apply`。**

### B3 原生门禁，用 B 自己的日志举证
```

```
- A 机没有的样本就自己造：从 `--good` 复制一份，把 `step/end(T,S)` 后面再插一份同样的 `step/end(T,S)`+`step/start(T,S)`，seq 整体重排保持连续，压回 zstd（首帧只放 header 一条记录）。
